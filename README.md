# 今晚谁出局

3 对 3 的歌手淘汰博弈小游戏。打开就能玩：**https://zhangzeyu97.github.io/tonight-out/**

## 规则

1. 双方各带 3 位蒙面歌手。每位歌手有 5 首拿手歌，分数分别是 1 到 5。
2. 每轮所有在场歌手同时各唱一首自己还没唱过的歌。
3. 全场最低分的歌手出局。几位同为最低时，随机淘汰其中一位，可能是任何一方的人。
4. 先淘汰对方全部 3 位歌手的一方获胜。一局最多 5 轮。

唱高分能保命，但好歌唱一首少一首。

## 三个对手

| 难度 | 对手 | 风格 |
|---|---|---|
| 新人 | 愣头青 | 总想先唱最好的歌，偶尔乱唱 |
| 职业 | 教科书 | 按博弈论精确求出的最优解（纳什均衡）随机出招，长期来看你最多和它打平 |
| 魔王 | 读心评委 | 以最优解为底，记住你每一轮的出招习惯并专门克制 |

AI 不用大模型。整个游戏约 9,600 个局面，每个局面的最优混合策略都离线精确解出，打包在页面里。每轮对手先锁定出招并公布 SHA-256 指纹，揭晓后可以核对，证明它没偷看你的选择。

## 技术

单个静态 HTML 文件，没有后端，也不加载任何第三方资源，国内网络也能直接打开。
