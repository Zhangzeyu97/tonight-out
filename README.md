# 今晚谁出局 · Who's Out Tonight

古典乐坛淘汰赛：3 对 3 的音乐大师心理博弈小游戏，中英双语。打开就能玩：**https://zhangzeyu97.github.io/tonight-out/**

A 3-vs-3 classical-music mind game in Chinese and English. Play in the browser: **https://zhangzeyu97.github.io/tonight-out/**

## 规则

1. 双方各派 3 位大师。每位大师有 1 到 5 分五种发挥，每种只能用一次。
2. 每轮所有人同时上台演奏。
3. 全场最低分出局。几位同为最低时，随机淘汰其中一位，可能是任何一方的人。
4. 先淘汰对方全部 3 位大师的一方获胜。一局最多 5 轮。

每首曲子有一个封神版和三个翻车版（琴凳塌了、猫来弹琴了、天鹅变鸭子了……）。谁以低分出局，就随机放一段翻车，再被钩子拖下台；高分却抽签出局的，封神版刚开头就被一声锣打断。终局有 MVP 封神画面、最佳翻车奖和可保存的战报图。

每日一演：每天全网同一局（同样的阵容和对手出招种子），可以复制当日战报。翻车图鉴：18 种翻车要在比赛里遇到才解锁。

## 首发阵容

贝多芬《致爱丽丝》· 莫扎特《弦乐小夜曲》· 巴赫《托卡塔与赋格》· 肖邦《夜曲》· 维瓦尔第《四季·春》· 柴可夫斯基《天鹅湖》

## 三个对手

| 难度 | 对手 | 风格 |
|---|---|---|
| 新人 | 愣头青 | 总想先用最好的发挥，偶尔乱出 |
| 职业 | 教科书 | 按博弈论精确求出的最优解（纳什均衡）随机出招，长期来看你最多和它打平 |
| 魔王 | 读心评委 | 以最优解为底，揣摩你的习惯并专门克制；发现你在设套就收手 |

AI 不用大模型。整个游戏约 9,600 个局面，每个局面的最优混合策略都离线精确解出，打包在页面里。读心评委同时运行六个习惯模型，只在有把握时才偏离最优解，偏离幅度受风险预算约束；如果偏离之后反而吃亏，它会自动退回最优解。

每轮对手先锁定出招并公布 SHA-256 指纹，揭晓后可以核对，证明它没偷看你的选择。每一步都有评级（妙手 / 最优解 / 好棋 / 欠佳 / 失误 / 大漏），对照的是对手这一轮真实的出招策略；每局结束会把胜率变化拆成出招、猜招、抽签三部分，并找出转折点。

## 素材与许可

- 曲目：全部是作曲家去世百年以上的公有领域作品。录音由本项目用开源音色库自行合成演奏，不使用任何商业录音。
- 音色库：MuseScore_General.sf2，MIT 许可（基于 FluidR3），见 `assets/audio/credits.json`。
- 肖像：维基共享资源上的公有领域油画，经裁剪和调色。出处见 `assets/portraits/credits.json`：
  - 贝多芬：Joseph Karl Stieler, 1820
  - 莫扎特：Barbara Krafft, 1819
  - 巴赫：Elias Gottlob Haussmann, 1748
  - 肖邦：Ary Scheffer, 1847
  - 维瓦尔第：佚名，约 1723
  - 柴可夫斯基：Nikolai Kuznetsov
- 字体：ZCOOL QingKe HuangYou、Big Shoulders Display，均为 SIL Open Font License 1.1，裁剪后内嵌，许可证见 `fonts/`。

单个静态页面加少量图片和音频，没有后端，也不加载任何第三方资源，国内网络也能直接打开。
