# 今晚谁出局 · Who's Out Tonight

3 对 3 的歌手淘汰博弈小游戏，中英双语。打开就能玩：**https://zhangzeyu97.github.io/tonight-out/**

A 3-vs-3 singer elimination mind game in Chinese and English. Play in the browser: **https://zhangzeyu97.github.io/tonight-out/**

## 规则

1. 双方各带 3 位蒙面歌手。每位歌手有 5 首拿手歌，分数分别是 1 到 5。
2. 每轮所有在场歌手同时各唱一首自己还没唱过的歌。
3. 全场最低分的歌手出局。几位同为最低时，随机淘汰其中一位，可能是任何一方的人。
4. 先淘汰对方全部 3 位歌手的一方获胜。一局最多 5 轮。

唱高分能保命，但好歌唱一首少一首。

## 三个对手

| 难度 | 对手 | 风格 |
|---|---|---|
| 新人 | 愣头青 | 总想先唱最好的歌，偶尔乱唱 |
| 职业 | 教科书 | 按博弈论精确求出的最优解（纳什均衡）随机出招，长期来看你最多和它打平 |
| 魔王 | 读心评委 | 以最优解为底，揣摩你的习惯并专门克制；发现你在设套就收手 |

AI 不用大模型。整个游戏约 9,600 个局面，每个局面的最优混合策略都离线精确解出，打包在页面里。

读心评委同时运行六个"习惯模型"：你爱唱几分、每一轮爱唱手里第几高的歌、丢了人之后会不会加码、会不会跟着它上一轮的出招走、领先或落后时怎么唱。哪个模型猜得准，就更听哪个。它只在有把握时才偏离最优解，偏离的幅度受风险预算约束：本局你已经"送"出的优势，加上它对你习惯的把握程度。如果偏离之后反而吃亏（说明你在反过来算计它），它会自动退回最优解。

在模拟测试里，对一直唱最高分的玩家，它把对方胜率压到 3%；对完全按最优解出招的玩家，它仍然保持约 50% 的公平局面。

每轮对手先锁定出招并公布 SHA-256 指纹，揭晓后可以核对，证明它没偷看你的选择。
